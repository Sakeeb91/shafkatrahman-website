# Social icons

LinkedIn, GitHub, X, and Threads are from [Bootstrap Icons v1.13.1](https://github.com/twbs/icons/tree/v1.13.1/icons), under the included MIT license.

The upstream `twitter-x.svg` is saved here as `x.svg`. The SVG paths are unchanged. CSS masks give the icons the link's theme-aware text color. Each icon-only link has a descriptive accessible name and a native title tooltip.
